# Coherence 0.2.0

**Not signed yet.** Check the installer's SHA-256 against `SHA256SUMS.txt` before running it.

## What is new

- **A Windows app.** A per-user installer, no administrator rights. Coherence opens in its own window (WebView2), with
  a tray icon and your browser as a fallback. It runs on a private Node.js runtime, so nothing else needs installing.
- **No PowerShell at run time.** File protection, Windows folders, saved-key encryption and the folder chooser go
  through the native `CoherencePlatform.exe`. This means Coherence can run where script hosts are blocked.
- **Safer data:**
  - data saved by a newer version is refused instead of overwritten;
  - format changes run as backed-up, journalled migrations;
  - saved keys Windows cannot unlock no longer stop Coherence: settings open read-only, with **Reset saved keys**;
  - a restored or copied settings folder asks whether to use it or start fresh.
- **Recover and back up projects:**
  - **Find Coherence projects in a folder** (including Trash);
  - **Remove from library** for projects whose folder is gone;
  - **Export project as .zip**;
  - projects restored to their original folder reconnect.
- **OneDrive and network Documents:** new projects default to a local folder instead, and the app explains why.
- **Clear Windows messages:** start-up problems explain themselves, and a Controlled Folder Access block names the
  programs to allow.
- **The name Coherence everywhere you see it:**
  - generated files say "Generated by Coherence";
  - tracker items carry the `coherence` label or tag;
  - the CSV export is `coherence-use-cases.csv`.

  Files and tracker items written by earlier builds are still recognised.

## AI runs and connections

- **Runs explain themselves.** A run that stops says why in plain words (for example "No API key is saved for
  OpenRouter", or "OpenRouter's rate limit was reached; it should reset at about 10:00") and offers **Try again**,
  **Change models** or **Abandon run**.
- **Try again resumes.** The screen readings, journey map, plan and every use case a stopped run finished are reused,
  as long as the models and settings stay the same.
- **Rate limits pause instead of wasting the run.** Coherence reads the service's reset time, stops every request to
  that model together, and never swaps in lower-quality substitutes because of a limit.
- **Long runs show their progress:** the activity panel lists each AI request with what it is doing, such as "Writing
  UC-007 · 12,400 characters so far" or "thinking…".
- **AI answers stream**, so a slow but working model is no longer cut off after three minutes.
- **Setting up OpenAI-compatible services is easier:**
  - recognised addresses to choose from (OpenRouter, Groq, DeepSeek, Together AI, Mistral, xAI);
  - pasted addresses are tidied;
  - Coherence finds the `/v1` address on the same server;
  - plain messages about keys and addresses;
  - a documented key check where the service offers one.
- **Keys are safer:** a key you type is no longer wiped when you change the address. A connection without a key says
  so, and a run that needs one stops before any work.
- **Removing a connection** is a visible button. It says what uses the connection, and offers to move those to a
  connection with the same models.
- **The Analysis page explains a blocked start** beside the button, with one-click fixes such as "Read screens with
  *a model that reads screenshots*".

## Known limitations

- Windows 11 x64 only; not signed, so SmartScreen and Smart App Control may warn or block.
- No proxy support. Browser policies that block local `file://` pages break the browser fallback.
- OneDrive-synced, network and cloud-only project folders are not supported.
- Not yet tested on clean VMs: Smart App Control, AppLocker or Controlled Folder Access, all-users installs.
- No in-app update check yet: there is no published release channel to check against.
